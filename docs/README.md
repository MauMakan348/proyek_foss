# Proyek FOSS

## Deskripsi
Proyek ini merupakan latihan pengelolaan berkas dan direktori
dalam lingkungan Linux sebagai bagian dari pembelajaran Open Source.

## Struktur Direktori
- src: menyimpan kode sumber.
- docs: menyimpan dokumentasi.
- tests: menyimpan berkas pengujian.
- bin: menyimpan skrip atau program yang dapat dijalankan.

## Tujuan
Mempelajari pengelolaan proyek FOSS, penggunaan Linux CLI,
dan penerapan Version Control System menggunakan Git.
