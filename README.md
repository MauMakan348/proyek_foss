# Proyek FOSS

## Deskripsi
Proyek ini merupakan latihan pengelolaan proyek perangkat lunak
Open Source menggunakan lingkungan Linux dan Git.

## Struktur Direktori
- src: menyimpan kode sumber program.
- docs: menyimpan dokumentasi proyek.
- tests: menyimpan skrip dan berkas pengujian.
- bin: menyimpan program atau skrip siap dijalankan.

## Teknologi
- Linux
- Bash Shell
- Git dan GitHub

## Cara Menjalankan
Jalankan program utama dengan perintah `bash src/main.sh`.

Untuk memeriksa struktur direktori, jalankan
`bash tests/deploy_app.sh`.

## Tujuan Pembelajaran
Mempelajari pengelolaan proyek FOSS, penggunaan Linux CLI,
serta penerapan Version Control System.
